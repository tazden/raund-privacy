# РАУНД — политика конфиденциальности

Статическая страница политики для Android-приложения `ru.raund.sport`. Редакция от 9 ноября 2026 года соответствует проверенным потокам данных версии 1.2.3+8 и описывает обработку сведений на внешних страницах партнёров.

## Состав

- `index.html` — самостоятельная страница с адаптивной вёрсткой и встроенными стилями.
- `.nojekyll` — отключает обработку Jekyll при размещении на GitHub Pages.
- `.gitignore` — исключает локальные системные файлы и материалы проверки.

Зависимости, сборка, JavaScript, формы, внешние шрифты и изображения отсутствуют. Для GitHub Pages достаточно публикации корня выбранной ветки репозитория. Издатель приложения и оператор обработки данных — Щукин Даниил. Контакт поддержки: `pierrejeter1903@adminis.ru`.

## Размещение

Страница предназначена для прямой раздачи по HTTPS. Внешние ссылки ведут на официальные страницы о конфиденциальности Firebase и GitHub, а адрес поддержки использует `mailto:`. CSP запрещает загрузку сетевых ресурсов, выполнение скриптов и отправку форм; встроенные стили разрешены. Содержание страницы должно обновляться вместе с изменениями обработки данных в приложении.
